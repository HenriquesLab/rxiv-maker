# Installation

The full installation guide, with per-platform LaTeX instructions, lives on the website:

**[Installation guide →](https://rxiv-maker.henriqueslab.org/getting-started/installation/)**

Quick version:

```bash
brew install henriqueslab/formulas/rxiv-maker   # macOS (includes LaTeX)
pipx install rxiv-maker                          # Linux / Windows (WSL)
rxiv check-installation                          # verify
```

LaTeX is required. See the [website guide](https://rxiv-maker.henriqueslab.org/getting-started/installation/) for platform-specific LaTeX setup.
