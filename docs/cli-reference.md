# CLI Reference

The complete command reference lives on the website:

**[CLI Reference →](https://rxiv-maker.henriqueslab.org/api/)**

Most-used commands:

```bash
rxiv init my-paper          # create a new manuscript
rxiv pdf                    # build the PDF
rxiv validate               # check the manuscript
rxiv docx                   # export to Word
rxiv arxiv                  # prepare an arXiv submission
rxiv track-changes v1 v2    # diff two versions
rxiv clean                  # remove generated files
```

Run `rxiv --help` or `rxiv <command> --help` for details.
